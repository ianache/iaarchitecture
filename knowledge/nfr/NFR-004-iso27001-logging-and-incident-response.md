title: Security monitoring, logging, and incident response
summary: Systems must produce security-relevant evidence, monitor for suspicious activity, and support a defined incident response process required by ISO 27001.
type: STANDARD
status: DRAFT
tags: [nfr, iso27001, security, monitoring, incident-response]
---
Security monitoring and incident handling must be designed as part of the operating model, not added ad hoc after a breach.

Requirements:
- Security-relevant events must be logged with timestamps, user or service identity, source, action, and outcome.
- Logs must be protected from tampering, retained according to policy, and reviewed for anomalies or policy violations.
- Security incidents must be triaged, assessed, contained, and reported with defined escalation paths and ownership.
- Recovery and lessons learned must be recorded to improve the control environment and reduce recurrence.

This requirement aligns with ISO/IEC 27001 controls for monitoring, logging, and response to security events.
